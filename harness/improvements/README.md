# Improvement reports

The `harness-improvement-researcher` agent writes a report here every time
it investigates how to improve the harness itself (not the project it is
building) — new agent-harness patterns, better memory/context management,
skills worth adopting, and so on.

Each report is a new dated file: `YYYY-MM-DD-proposals.md`. It never
implements a proposal on its own — everything goes through user approval
and then the planner, per `harness/agents/agent-harness-improvement-researcher.md`.

This directory starts empty in a new project — the first report lands here
once the agent runs for the first time.
