# Project history

Narrative record maintained by the [historian agent](../agents/agent-historian.md)
— what was learned, what failed and how it got resolved, how the site and
the harness were built over time. This is different from
[memory/](../memory/) (which is operational state for agents); this is
material meant, from day one, to be input for public content — the
[content-writer](../agents/agent-content-writer.md) or
[content-researcher](../agents/agent-content-researcher.md) use it later for
a "how we built this" blog.

Not everything that happens goes in here — see the criteria in
`agents/agent-historian.md` ("what warrants an entry"). Each file is named
`YYYY-MM-DD-short-title.md`.
