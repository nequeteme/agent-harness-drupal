# Roadmap

Overview of phases and tasks, maintained by
[project-writer](../../agents/agent-project-writer.md) as a readable mirror
in the repo of the visual project board on GitHub. Each phase links to its
Issues.

Use this file to track epics/phases at a glance — status per phase, known
pending items per phase, and a running list of work items that come up after
a given epic closes. Fill in one section per epic, and a table of
post-epic/ad-hoc work below it, updated by the documenter as phases and
tasks change status.
