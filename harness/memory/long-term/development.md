# Drupal development (backend)

Consolidated knowledge — data-model and content patterns that have already
proven stable and repeat, so that `drupal-developer`/`content-writer`/
`planner` don't have to re-derive them every time.

This is where the real content architecture of the project gets recorded
(content types, Paragraph types or equivalent structured-content model, how
they relate to each other) once it has been confirmed against the actual
codebase — plus any correction to a previous assumption once it is verified
against the filesystem/config rather than inferred. Written by the
[documenter](../../agents/agent-documenter.md) based on what
`drupal-developer` reports. See also
[long-term/frontend.md](frontend.md) for the rendering-layer patterns that
consume this same content model.
