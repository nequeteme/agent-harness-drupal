# Historia del proyecto

Registro narrativo mantenido por el [agente historiador](../agentes/agente-historiador.md)
— qué se aprendió, qué falló y cómo se resolvió, cómo se fue construyendo el
sitio y el harness. Es distinto de [memoria/](../memoria/) (que es estado
operativo para los agentes); esto es material pensado desde el día uno como
insumo para contenido público — el
[creador-contenidos](../agentes/agente-creador-contenidos.md) o el
[investigador-contenidos](../agentes/agente-investigador-contenidos.md) lo
usan más adelante para un blog de "cómo construimos esto".

No todo lo que pasa entra acá — ver el criterio en
`agentes/agente-historiador.md` ("qué amerita una entrada"). Cada archivo es
`YYYY-MM-DD-titulo-corto.md`.
